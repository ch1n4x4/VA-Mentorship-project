# VA ETHICAL HACKING PROJECT

## Objective

### This project is divided into four distinct parts wit objectives as follows;
#### **Project 1**: Insecure Direct Object References (IDOR)
The objective of this section is to identify and exploit a vulnerability in a web application’s "Live Chat" feature. Key tasks include: Vulnerability Identification, Exploitation (PoC), Remediation Planning.
#### **Project 2**: PCAP File Analysis
The objective of this section is to analyze network traffic to recover a Wi-Fi password. Key tasks include: Handshake Confirmation, Password Recovery, Security Analysis.
#### **Project 3**: SQL Injection (SQLi) at Medium Security Level
The objective is to bypass an existing security layer in the Damn Vulnerable Web Application (DVWA). Key tasks include: Defense Analysis, Exploitation, Remediation.
#### **Project 4**: Building a Secure Login Module
The objective of this final part is to develop a secure backend to replace the vulnerable PHP code. Key tasks include: Secure Implementation, Validation of Security

### Skills Learned

- Web Application Security & Pentesting
- Network Security & Cryptanalysis
- Database Security & Secure Coding
- Compliance & Reporting
